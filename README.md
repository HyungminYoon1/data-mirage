관측값을 직접 생성하고 분석 규칙을 바꾸며 결론을 조사하는 여섯 가지 통계 실험입니다. 기존 축·표본·심슨 사례에 중간 중단/다중 비교, 상관의 혼입/이상치, 반복 표집/추정 구간 수사를 추가했습니다. 모든 값은 가상 시뮬레이션이며 실제 통계·의료 자료가 아닙니다.

이 업그레이드는 **LOCAL ONLY**입니다. 위 공개 링크가 이번 변경을 반영한다는 의미는 아닙니다. 이번 작업의 브라우저·공개 사이트·원격 CI 검증은 NOT_RUN입니다.

## 직접 해보기

- 동일한 값의 원본/축 편집본 비교, 실제 증가율 퀴즈
- 가상 200명에서 무작위·고점수·저점수 표본을 중복 없이 추출
- 표본 수와 다시 뽑기, 실제 평균·차이·분포 표시
- 쉬운/어려운 과제 구성 변경으로 심슨의 역설 비교
- **유의성 사냥:** 1…12지표를 각 80회 생성. 최종 시점만 검사하거나 20·40·60·80회에서 첫 발견까지 관찰합니다. 양측 정확 이항 p와 Bonferroni 가족 보정을 적용하고, 같은 관측의 네 규칙 결과·160회 발견률·전체 0/1 원자료를 대조합니다. 차이 없음 세계와 지표 1에만 신호가 있는 세계를 선택할 수 있습니다.
- **상관 수사:** 두 집단의 위치 차이와 영향력 큰 한 점이라는 두 생성 세계. 전체/집단 평균 제거/24번 제외 산점도, 집단별 분모, 모든 관측의 한 점 제외 r을 비교합니다. 민감도 진단과 정당한 관측 삭제·인과 해석을 구분합니다.
- **구간의 약속:** 120/200개의 1 토큰에서 20·80·200회 독립 복원 추출. Hoeffding 구간의 90·95·99% 포함 확률 하한, 전체 풀과 편향된 120/140 풀, 160회 목표 포함률과 각 구간을 비교합니다. 표본 수를 늘려도 편향은 남는 상황을 직접 확인합니다.
- 새 미션마다 세 가지 판단 선택과 구체적인 오답 설명이 있습니다. 조건을 바꾸면 선택한 답을 현재 설계와 계산 결과로 다시 판정합니다.
- 새 무작위 실험은 브라우저에서 시드를 뽑습니다. 표시된 시드 1…4294967295와 동일 조건으로 재현할 수 있습니다. 조건만 바꾸면 같은 원자료를 재분석하며, 표본 크기/지표 수를 늘리면 기존 관측의 접두부를 유지합니다.

개인 소개나 계정 없이 사용할 수 있습니다. 새로고침하면 실험 상태가 초기화됩니다.

## 가정과 분모

유의성 사냥은 H0: p=0.5인 정확 양측 이항 검정입니다. 가족 크기는 지표 수 × 계획 시점 수이고, 보정 문턱은 0.05/가족 크기입니다. 시점 사이에는 같은 누적 자료를 쓰므로 의존성이 있습니다. Bonferroni의 합집합 상계는 시점 사이의 독립성을 요구하지 않습니다. 신호 세계의 발견률은 ‘적어도 하나 기각’이며 올바른 지표를 발견한 비율이나 진실의 확률이 아닙니다.

상관 자료는 24개의 생성 좌표입니다. 집단 중심화는 집단의 위치 차이를 제거하는 기술적 비교이고 인과 추정은 아닙니다. 1점 집단의 Pearson r는 미정의로 표시합니다. 모든 원자료와 한 점 제외 결과를 열어 확인할 수 있습니다.

구간은 평균 ± √[ln(2/α)/(2n)]을 [0,1]로 제한합니다. 이상적인 독립 복원 표집에서 선택 풀의 평균에 대한 포함 확률 ≥ 1−α를 보장하는 보수적 Hoeffding 절차입니다. 기존 점수 표본 실험은 비복원, 새 구간 실험은 복원 추출입니다. 편향 풀을 쓰면 보장 대상은 전체 200개가 아닌 선택한 140개의 평균입니다. 한 번의 구간이 참값을 포함할 사후확률로 해석하지 않습니다.

반복 실험은 각 160회이며 현재 한 실험과 별도 시드를 사용합니다. 산점도의 축 범위, 관측 수, 성공/시도, 원자료 및 반복 결과를 표시합니다. 의사난수는 재현성을 위한 도구이며 시뮬레이션 빈도가 수학적 보장을 입증하지 않습니다.

참고 개념: [원문과 추가 학습](https://seeing-theory.brown.edu/). 구현은 이 저장소의 계산 모델과 UI로 작성했습니다.

## 실행 및 검증

Node.js 22 이상. 외부 패키지는 없습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

기존 워크플로는 main에 푸시하면 검증 후 dist만 GitHub Pages에 배포하도록 구성되어 있습니다. 이번 작업에서는 커밋·푸시·배포를 하지 않습니다. 외부 패키지·API·폰트·이미지 자산이 없으며 CSP는 런타임 연결을 차단합니다. 계산 모델은 DOM이나 UI 모듈을 참조하지 않습니다. 실험 상태는 페이지 메모리에만 남고, 업로드·계정·추적·브라우저 저장소 기능은 없습니다. 호스팅 로그와 앱의 데이터 처리는 별개입니다.

LOCAL 검증: 독립 확률 분포 합성/순차 경로 계산, 해석 가능한 상관 반례, 정확 포함률과 수치적 경계 검증을 포함한 단위 테스트. 정적 검사는 모듈·DOM 참조, 순수 모델 경계, CSP, 원격 자산/런타임 네트워크·저장소 호출 부재, UTF-8 without BOM/CRLF를 검사합니다. 정적 검사는 실제 브라우저의 화면·동작을 검증하지 않습니다.

## 별도 브라우저 QA 흐름 (NOT_RUN)

`npm run dev -- 0`의 루프백 URL을 열고 시드 **42**를 입력한 뒤 재현합니다. 다음 수치는 모델에서 확인한 기대값이며 브라우저 실행 증거는 아닙니다.

1. 기존 사례: 축 51 → 높이 비율 5배, 실제 증가율 약 7.7%. 높은 점수 표본 80명 → 모집단과 다른 평균. 심슨 A 쉬움 10/B 쉬움 80 → 전체 B, 양쪽 40 → 전체 A.
2. 유의성 사냥: 6지표·차이 없음·중간 확인·각 5% → 지표 5의 15/20, p≈0.041389에서 발견, 160회 중 79회 기각. 보정으로 변경 → 이번 기각 없음, 3/160회. 최종 시점만 검사 → 이번 기각 없음. 단일 검정 답을 고른 뒤 1지표/최종 ↔ 여러 시점으로 바꾸면 답의 판정도 달라져야 합니다.
3. 상관 수사: 집단 혼입 → 전체 r≈0.854, 중심화 r≈−0.905, 각 집단 12점. 한 점 세계 → 전체 r≈0.756, 24번 제외 r≈−0.972. 집단별 r·24점 원자료·한 점 제외 결과를 열고 답을 선택한 후 세계를 변경해 재판정을 확인합니다.
4. 구간: 200회·95%·전체 풀 → 이번 123/200, 구간 약 [0.519,0.711], 목표 포함 158/160회. 편향 풀 → 이번 169/200, 약 [0.749,0.941], 목표 포함 0/160회. 표본 수·확률 하한을 바꿔 폭과 분모를 확인하고, 복원 추출 번호의 반복을 확인합니다.
5. 새 무작위 실험 → 표시 시드 변경. 시드 42·같은 조건 복원 → 위 결과 재현. 0·소수·상한 초과 시드 → 오류 안내와 기존 결과 유지. 버튼·방향키/Home/End로 여섯 탭을 이동하고 320/390px에서 가로 넘침·표 스크롤·그래프/피드백·콘솔 오류를 점검합니다. WebMCP는 지원/미지원 브라우저를 별도로 확인합니다.
